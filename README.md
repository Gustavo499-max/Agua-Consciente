# 💧 Água Consciente

Aplicação web educacional para estimar o consumo doméstico
de água e ajudar usuários a identificar oportunidades de economia.

## Funcionalidades

✅ Calculadora de consumo
✅ Estimativa diária e mensal
✅ Estimativa de custo
✅ Comparação com média nacional
✅ Distribuição por atividade
✅ Recomendações personalizadas

## Tecnologias

HTML5
CSS3
JavaScript

## Como executar

1. Clone o repositório
2. Abra index.html no navegador
